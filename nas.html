01 / The Problem

Why Search for
Architecture?

Designing neural networks is traditionally a manual, intuition-driven process. NAS reframes this as an optimization problem: given a dataset and a set of constraints, algorithmically find the topology, depth, width, and connectivity that maximize predictive performance.

Search Space

The universe of all possible architectures. Defined by operations (convolutions, pooling) and connectivity patterns (chains, DAGs, cells).

10^28

Search Strategy

The algorithm navigating the space. RL agents, evolutionary algorithms, or gradient descent on continuous relaxations.

3

Performance Estimation

How to evaluate a candidate architecture without training to convergence. Proxy tasks, weight sharing, and one-shot methods reduce cost.

10x

Result

A discovered architecture that often outperforms hand-designed counterparts, with fewer parameters and lower latency.

03 / Methods

Search
Strategies

The choice of search strategy defines how the algorithm explores the combinatorial space of architectures. Each method balances exploration, exploitation, and computational cost differently.

01
Reinforcement Learning
→

A controller RNN generates architecture descriptions (strings) sampled from a learned policy. Each generated architecture is trained and evaluated. The resulting validation accuracy serves as the reward signal, updating the controller via policy gradient (REINFORCE). Over time, the controller learns to generate higher-performing architectures.

02
Evolutionary Algorithms
→

Starting from a population of simple architectures, evolutionary methods apply mutations (add/remove layers, change operations) and crossovers. Only the fittest survive to the next generation. This mimics natural selection, gradually evolving complex, high-performing networks without gradient-based optimization.

03
Gradient-Based (DARTS)
→

Differentiable Architecture Search (DARTS) relaxs the discrete search space into a continuous one by placing a mixture of candidate operations on each edge. Architecture weights (alphas) and network weights are optimized jointly via gradient descent. After convergence, the strongest operations are selected to form the final discrete architecture.
