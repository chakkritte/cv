How to use the LaTeX table generator

1

Set table size via File → New table or use + Row / + Col buttons.

2

Double-click any cell to edit. Use Tab and arrow keys to navigate.

3

Adjust alignment and borders with the toolbar or Table / Column / Row menus.

4

Click ⚡ Generate, then Copy to Clipboard and paste into your LaTeX document.
